\subsection{Splitter artifact}
\label{sec:splitter-artifact}

We provide an accompanying artifact containing explicit row families for
several $(c,k,k)$-splitters.  A row family $\mathcal F\subseteq 2^{[c]}$ is a
$(c,k,k)$-splitter if for every pair of disjoint sets $A,B\subseteq[c]$ with
$|A|=|B|=k$, there exists $S\in\mathcal F$ such that $A\subseteq S$ and
$S\cap B=\emptyset$.  Each row file in the artifact is a plain text certificate:
line $j$ is a binary string of length $c$ encoding one set $S_j\subseteq[c]$.

The artifact includes a self-contained verifier.  Given a row file, the verifier
checks the defining condition exactly; for the larger symmetric instances it
uses explicit group actions only to reduce the number of representative demands,
and then checks the same containment and disjointness condition.  No external
solver is required to verify the released certificates.

by the released row counts, before applying any composition operation.  If a
row family has $N$ rows, the corresponding raw exponent is denoted by $E$ and
we report the base $2^E$.
